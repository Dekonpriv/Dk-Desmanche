## 📌 Sobre o projeto

O **[Dk]Desmanche** é um resource desenvolvido para o Multi Theft Auto: San Andreas (MTA:SA), que permite realizar o desmanche de veículos com acesso restrito aos jogadores autorizados.

O sistema utiliza a ACL `(DESMANCHE)` para controlar quem pode utilizar a funcionalidade, oferecendo uma solução simples para servidores que desejam implementar esse tipo de atividade.

Esta versão é uma atualização do script originalmente publicado em meu Discord como **Desmanche 1.0**.

## ⚙️ Funcionalidades

- 🚗 Sistema de desmanche de veículos.
- 🔐 Controle de acesso por ACL.
- 👮 Uso restrito ao grupo `(DESMANCHE)`.
- 🛠️ Resource desenvolvido para MTA:SA.

## 📥 Instalação

1. Baixe os arquivos deste repositório.
2. Coloque a pasta do resource no diretório `resources` do servidor.
3. Confira o arquivo `meta.xml` e os arquivos Lua.
4. Verifique se o grupo `(DESMANCHE)` está configurado corretamente na ACL do servidor.
5. Inicie o resource pelo console do MTA:SA.

## 🔑 Permissões

O acesso ao sistema é controlado pela ACL do servidor.

**Grupo necessário:** `(DESMANCHE)`

Certifique-se de que o nome corresponda exatamente ao grupo utilizado pelo script.
